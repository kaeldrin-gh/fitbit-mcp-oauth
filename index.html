Fitbit MCP (personal)

A personal, single-user tool that lets my local AI assistant read my own Fitbit data through the Google Health API.

  • Read-only. The app requests only read-only scopes (activity, sleep, health metrics, nutrition, profile, settings). It cannot create, change or delete any health data.
  • Local. It runs entirely on the owner's computer. There is no hosted service, no user accounts and no server operated by this project.
  • Not a public product. It is not offered to other users.

Built on the open-source google-health-fitbit-mcp server.
