# fitbit-mcp-oauth

Homepage and privacy policy for a personal Google OAuth app that lets a local MCP server
([google-health-fitbit-mcp](https://github.com/BerkKilicoglu/google-health-fitbit-mcp)) read my own
Fitbit data from the Google Health API, read-only.

Published with GitHub Pages:

- Homepage: https://kaeldrin-gh.github.io/fitbit-mcp-oauth/
- Privacy policy: https://kaeldrin-gh.github.io/fitbit-mcp-oauth/privacy.html
