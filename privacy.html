Privacy Policy

Last updated: 29 September 2026

What this app is

Fitbit MCP (personal) is a single-user tool that runs on its owner's own computer and lets a local AI assistant read the owner's Fitbit data from the Google Health API. It is not a public service.

Data accessed

With your consent, the app reads data from your Google Health account using read-only OAuth scopes: activity and fitness, sleep, health metrics and measurements, nutrition, profile and settings. It does not request write, ECG or irregular-rhythm scopes and cannot create, modify or delete your data.

How data is used and stored

  • Data is fetched on request and passed to the AI assistant running on the same computer, only to answer the signed-in user's own questions.
  • OAuth tokens and app settings are stored only on that computer, in the user's home folder (~/.google-health-mcp).
  • No data is sent to any server operated by this project. The app connects only to Google's OAuth and Google Health API endpoints.

Sharing

Data obtained from Google APIs is not sold, shared with third parties, used for advertising, or used to train models. This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Revoke access at any time at myaccount.google.com/permissions.
  • Delete local data by removing the ~/.google-health-mcp folder.

Contact

Questions about this policy: open an issue at github.com/kaeldrin-gh/fitbit-mcp-oauth/issues.
